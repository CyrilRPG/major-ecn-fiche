# Polices embarquées

Pour un rendu fidèle à la charte « luxe médical », placez ici les fichiers
`.ttf` suivants. En leur absence, WeasyPrint et Word utilisent automatiquement
les polices de repli (Times New Roman / Helvetica / Arial).

| Police               | Fichiers attendus                                                                 | Usage                     |
|----------------------|-----------------------------------------------------------------------------------|---------------------------|
| **Playfair Display** | `PlayfairDisplay-Regular.ttf`, `PlayfairDisplay-Bold.ttf`, `PlayfairDisplay-Italic.ttf` | Titres, page de garde     |
| **Cormorant Garamond** | `CormorantGaramond-Regular.ttf`, `CormorantGaramond-SemiBold.ttf`, `CormorantGaramond-Italic.ttf` | Sous-titres               |
| **Inter**            | `Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf`, `Inter-Bold.ttf`, `Inter-Italic.ttf` | Corps de texte            |
| **JetBrains Mono**   | `JetBrainsMono-Regular.ttf`                                                       | Valeurs chiffrées (option) |

## Téléchargement

Ces polices sont gratuites et disponibles sur Google Fonts :

- Playfair Display — <https://fonts.google.com/specimen/Playfair+Display>
- Cormorant Garamond — <https://fonts.google.com/specimen/Cormorant+Garamond>
- Inter — <https://fonts.google.com/specimen/Inter>
- JetBrains Mono — <https://fonts.google.com/specimen/JetBrains+Mono>

Décompressez les archives et copiez les fichiers `.ttf` directement dans ce dossier
(les noms doivent correspondre exactement au tableau ci-dessus).
